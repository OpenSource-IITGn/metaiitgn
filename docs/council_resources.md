## How to Use This Page

- Click any link above to visit the corresponding website or resource
- External links open in a new tab
- If a link is broken or outdated, please [open an issue](https://github.com/OpenSource-IITGn/metaiitgn/issues/new) or submit a pull request to keep this directory current

## Contributing

This directory is community-maintained. To add a new council, resource, or link:

1. Fork the [metaiitgn repository](https://github.com/OpenSource-IITGn/metaiitgn)
2. Edit `docs/council_resources.md`
3. Submit a pull request with your changes

For detailed contribution steps, see [How to Contribute](howtocontribute.md).
